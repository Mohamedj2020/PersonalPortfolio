# Portfolio documentation

This is the documentation for [mohamedjirac.dev](https://mohamedjirac.dev), a modern single-page portfolio website built with **React 19**, **TypeScript**, and **Tailwind CSS**.

The site showcases professional experience, technical projects, skills, certifications, and a contact form — all driven by a single data file and rendered through modular React components.

## Tech stack

| Layer        | Technology                          |
| ------------ | ----------------------------------- |
| Framework    | React 19 with TypeScript            |
| Styling      | Tailwind CSS 3.4                    |
| Animations   | Framer Motion, CSS scroll animations |
| Contact form | Formspree (`@formspree/react`)      |
| Icons        | React Icons                         |
| Analytics    | Vercel Analytics & Speed Insights   |
| Deployment   | Vercel                              |

## Key design decisions

- **Single data source** — All content lives in `src/data.ts`. Update text, experience, and projects without touching components.
- **Scroll-triggered animations** — Sections fade in as they enter the viewport using an `IntersectionObserver`.
- **Dark theme** — A zinc-based dark palette with emerald accents, designed for readability.
- **Responsive layout** — Sidebar-plus-content layout on desktop, stacked on mobile.
