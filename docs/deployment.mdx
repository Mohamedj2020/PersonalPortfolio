The portfolio is configured for deployment on [Vercel](https://vercel.com/) with zero additional setup.

## Deploy to Vercel

<Steps>
  <Step title="Push to GitHub">
    Make sure your code is pushed to a GitHub repository.

    ```bash
    git add .
    git commit -m "Update portfolio"
    git push origin main
    ```
  </Step>
  <Step title="Connect to Vercel">
    1. Go to [vercel.com](https://vercel.com/) and sign in with GitHub.
    2. Click **Add New Project** and import your repository.
    3. Vercel auto-detects Create React App — no configuration changes needed.
    4. Click **Deploy**.
  </Step>
  <Step title="Set environment variables">
    In your Vercel project settings, add:

    | Variable                  | Value              |
    | ------------------------- | ------------------ |
    | `REACT_APP_FORMSPREE_ID`  | Your Formspree ID  |
  </Step>
</Steps>

Subsequent pushes to `main` trigger automatic deployments.

## Vercel configuration

The project includes a `vercel.json` that configures:

```json vercel.json
{
  "framework": "create-react-app",
  "buildCommand": "npm run build",
  "outputDirectory": "build",
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ],
  "headers": [
    {
      "source": "/static/(.*)",
      "headers": [
        { "key": "Cache-Control", "value": "public, max-age=31536000, immutable" }
      ]
    }
  ]
}
```

| Setting           | Purpose                                                     |
| ----------------- | ----------------------------------------------------------- |
| `rewrites`        | Routes all paths to `index.html` for client-side routing    |
| `headers`         | Sets aggressive caching on hashed static assets             |
| `outputDirectory` | Points to the `build/` folder generated by Create React App |

## Build locally

To create a production build without deploying:

```bash
npm run build
```

This generates an optimized bundle in the `build/` directory with:

- Minified JavaScript and CSS
- Content-hashed filenames for cache busting
- An `index.html` entry point

<Note>
  The `build/` directory is already included in the repository for reference. In production workflows, this folder is typically in `.gitignore` and generated fresh by the CI/CD pipeline.
</Note>

## Deploy to other platforms

The production build is a static site — any static hosting provider works.

<Tabs>
  <Tab title="Netlify">
    1. Connect your GitHub repo to Netlify.
    2. Set the build command to `npm run build`.
    3. Set the publish directory to `build`.
    4. Add a `public/_redirects` file (already included):

    ```
    /*    /index.html   200
    ```
  </Tab>
  <Tab title="GitHub Pages">
    1. Install the deployment package:

    ```bash
    npm install --save-dev gh-pages
    ```

    2. Add to `package.json`:

    ```json
    "homepage": "https://yourusername.github.io/PersonalPortfolio",
    "scripts": {
      "predeploy": "npm run build",
      "deploy": "gh-pages -d build"
    }
    ```

    3. Run `npm run deploy`.
  </Tab>
  <Tab title="Static server">
    Serve the `build/` directory with any static file server:

    ```bash
    npx serve -s build
    ```
  </Tab>
</Tabs>

## Custom domain

To use a custom domain on Vercel:

1. Go to your project's **Settings > Domains** in the Vercel dashboard.
2. Add your domain (for example, `mohamedjirac.dev`).
3. Update your DNS records as instructed by Vercel.

<Note>
  Custom domain configuration is done in the Vercel dashboard, not in code.
</Note>
